# Skills

Structured instructions that give AI agents the methodology for a specific engineering activity.
Each skill follows the open [Agent Skills](https://agentskills.io) specification: a folder containing a `SKILL.md`
(with `name` and `description` frontmatter) plus supporting references where required.

| Folder | Activity |
|---|---|
| [requirements](requirements/) | Requirements analysis |
| [architecture](architecture/) | Architecture and design |
| [development](development/) | Implementation |
| [code-review](code-review/) | Code review |
| [testing](testing/) | Testing and quality |
| [security](security/) | Security engineering |
| [devops](devops/) | Build, deployment and operations |
| [documentation](documentation/) | Documentation |
